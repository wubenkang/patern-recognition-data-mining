# 《互联网大厂推荐算法实战》快速上手阅读指南

> 作者：赵传霖（人民邮电出版社·异步图书，2024）
> 全书 318 页，10 章。本指南目标：**用 2~3 周时间，建立"召回 → 粗排 → 精排 → 重排 → 冷启动 → 评估"的完整心智模型**，并能看懂大厂论文与面经。

---

## 一、先判断：这本书适不适合你 / 怎么读

这本书最大的特点是 **"以问题驱动、以工业实战为锚"**，不是教科书式罗列模型。
作者反复强调几条核心思想，在阅读时务必先记住，它们贯穿全书：

1. **特征工程没有过时**（与"深度学习自动学特征"的口号唱反调）。
2. **Embedding 是推荐系统的"一等公民"**，比模型结构本身更重要。
3. **召回与排序是两类完全不同的问题**：召回是"从亿级里挑万级"，要"广撒网"；排序是"从万级里挑十级"，要"准"。
4. **业务理解 > 模型 SOTA**。模型只在很短的窗口内有红利，特征、目标、样本才是长期护城河。

**适合你（数据科学 + 正在学 LLM/NLP 背景）的读法：**
- NLP 里的 Word2Vec / 双塔 / 对比学习 / 多任务，几乎可以一一对应到推荐系统的同名章节，借此快速类比上手。
- 把推荐系统当成一个"超大规模的稀疏-Embedding-排序"系统来理解，会非常顺。

## 四、推荐系统原理速览（先看这一节，能省 50% 阅读时间）

### 4.1 推荐系统的"漏斗"是怎么回事

整个推荐链路本质是 **一个"逐级缩小、逐级精细"的漏斗**：

```
   亿级物料库          百万级           万级           千级           几十条
 ────────────► 召回 ───────► 粗排 ──────► 精排 ──────► 重排 ─────► 最终展示
   (rough recall)   (light rank)  (heavy rank)  (re-rank/diversify)
```

| 阶段 | 输入规模 | 输出规模 | 模型复杂度 | 时延预算 | 主流技术 |
|---|---|---|---|---|---|
| 召回 | 亿 | 万 | 极轻 | 几十 ms | 双塔 / 向量检索 / 协同过滤 / GCN |
| 粗排 | 万 | 千 | 轻 | ~10 ms | 双塔（带交叉） / 蒸馏小模型 |
| 精排 | 千 | 百 | 重 | ~50 ms | DIN / DIEN / MMoE / PLE / Transformer |
| 重排 | 百 | 几十 | 中 | ~20 ms | DPP / 序列重排 / 上下文 reranker |

**关键认知**：**召回的目标是"覆盖"，精排的目标是"区分"**。它们的训练样本、损失、指标都不一样。

### 4.2 召回为什么离不开 Embedding 和双塔

- 召回的本质：**让相似的 (user, item) 向量近，让不相似的远**。
- 因此训练目标是 **Pairwise / Listwise**（如 Sampled Softmax + In-batch Negatives）。
- **不能用 user-item 交叉特征**（否则不能预先离线建索引），所以是 user 塔 + item 塔分开。

NLP 类比：双塔 = 推荐版的 SBERT；Sampled Softmax ≈ 对比学习里的 InfoNCE。

### 4.3 精排为什么"鲜花着锦"

精排只对几千个候选打分，可以堆模型容量：
- **特征交叉**：FM → DeepFM → DCN
- **用户行为序列**：DIN（attention 看哪些历史行为对当前 item 重要）→ DIEN（GRU + attention）→ SIM（长序列检索）
- **多任务**：MMoE / PLE，把 CTR、CVR、时长、完播放在一个模型里 jointly 学

### 4.4 冷启动的 3 把武器

| 问题 | 武器 | 一句话原理 |
|---|---|---|
| 新内容没人点过 | **Bandit** | "拿点流量去探一探"，UCB / 汤普森给探索奖励 |
| 新内容/新用户特征稀疏 | **元学习 MAML / Meta-Embedding** | 学一个"能快速适配新任务的初始化" |
| 没有正样本对 | **对比学习** | 用数据增强自己造正样本（类比 NLP 里的 SimCSE） |

### 4.5 评估的两套体系

- **离线**：AUC / GAUC（用户内 AUC，更接近真实业务）/ HitRate@K / NDCG / MRR。
- **在线**：A/B 测试 + 灰度发布 + 统计显著性。
- **调 bug 心法**（这本书最值钱的一节）：
  - **冰山效应**：线下涨、线上不涨 —— 多半是数据穿越或样本选择偏差
  - **向量穿越**：训练用了未来信息
  - **剂量模型**：看曝光占比是否符合分发预期
  - **创编一致性**：模型预估的偏好分布和真实人群消费分布是否一致

## 六、阅读姿势建议

1. **第一遍：跳读 + 抓主线**（建议先按"四、原理速览"建立框架，再回头读每章导言和小结）。
2. **第二遍：精读 5 / 6 / 7 / 8 / 9**（这 5 章是核心干货，前 4 章是地基，第 10 章是软技能）。
3. **每章读完做一件事**：自己画一张"问题 → 思路 → 方案 → 工业坑点"的卡片放进 Obsidian vault，对应你 LLM 知识库里的笔记风格。
4. **配套实战**：用公开数据集（MovieLens / Amazon Reviews）跑一遍：① ItemCF 召回 → ② 双塔召回 → ③ DeepFM 精排 → ④ MMoE 多任务 → ⑤ AUC/GAUC 评估。这正好覆盖第 5~9 章。
5. **遇到拗口的术语**先去 Word2Vec / BERT 对照表（第五节）查一眼，往往秒懂。

## 七、一句话总结

> 这本书最值得反复读的是 **第 5 章（召回）+ 第 6 章（精排/重排）+ 第 9 章（评估调试）**。
> 它不教你"哪个模型最强"，而是教你 **"在什么阶段，该选什么样的模型，以及它会以什么方式坑你"** —— 这才是大厂工程师的核心能力。
